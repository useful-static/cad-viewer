How do I share a link to a view of a 3D CAD model?

Your file stays on your device. A view link carries the view, never the file itself.

  1. Open the model in cad.place from its web address (https://cad.place/?src=<the file's address>), and set up the view: turn it, cut it, hide or select parts, explode it.
  2. Choose File › Copy view link.
  3. Send the link. It opens the model at that view: the camera, projection, orientation, display style, section, explode, and the hidden and selected parts.

A model opened from your device has no web address, so its link holds the view alone, and cad.place says so. Whoever opens that link opens their own copy of the file, and the view is applied to it.

A link keeps working when the file is revised: parts are also found by name, and the page says when something no longer matches.
