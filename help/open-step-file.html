How do I open a STEP file online without installing CAD?

Your file stays on your device. cad.place reads it in your browser and never uploads it.

  1. Go to cad.place.
  2. Drop the file on the page, or choose it with Open… (in the File menu on a small screen).
  3. A STEP (.stp, .step), IGES (.igs, .iges) or BREP file is converted in your browser, with a progress card that shows each step. The assembly then opens with its parts tree.

Turn the model with one finger or the mouse, zoom with two fingers or the wheel, and press Fit to frame it again. The browser keeps each conversion on this device, so opening the same file again is quick.

cad.place also opens meshes (STL, OBJ, PLY, OFF, 3MF, glTF, GLB), 2D drawings (DXF, DWG) and a .zip holding any of them. It is free and needs no account.

Open a file that is online

Add the file's address after ?src=: https://cad.place/?src=https://example.com/part.step. The site that holds the file must allow it to be read from another page (CORS). When it does not, cad.place says so, and you can download the file and drop it on the page instead.
