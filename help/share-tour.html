How do I make and share a guided tour of a 3D CAD model?

A tour is a small file of steps. Each step is a view of the model with a title and a caption; the model itself stays where it is.

  1. Open the model in cad.place from its web address (https://cad.place/?src=<the file's address>), so the tour can name it.
  2. Choose File › Make a tour….
  3. For each step, set the view: pin notes with Measure first (turning Measure on turns Explode off), then turn it, colour parts, hide, cut or explode them. Then press Add step and give it a title and text.
  4. Press Preview to play it through, then Save tour. You get a .cadtour.json file.

With no site of your own, press Copy link instead: the link carries the whole tour, opens the model and plays it. A long tour can be too big for a link; then Save tour and send the file.

To share it from a site, put the file on a web address, next to the model or on a site that allows other sites to read it, and send this link: it opens the model the tour names and plays the tour.

https://cad.place/?tour=https://example.com/models/bracket.cadtour.json

To show it on your own page, embed the same link with embed=1:

<iframe src="https://cad.place/?embed=1&tour=https://example.com/models/bracket.cadtour.json" width="800" height="600" allowfullscreen></iframe>

A tour plays on one model. Models you added to the scene are not saved with it, and cad.place says so when you save.

A tour made on a model opened from your device names no model: whoever plays it opens the model first, then the tour (File › Make a tour… › Open…).
