How can I show 3D CAD models of my products on my website?

Your files stay on your site. Visitors' browsers fetch them from you and show them in cad.place; nothing is copied to cad.place.

1. Let the files be read

Put the models (STEP, IGES, STL, glTF and the rest) on your site, and have it send the CORS header Access-Control-Allow-Origin for them, so a page on another site may read them.

2. Link one model

https://cad.place/?src=https://example.com/models/bracket.step opens it.

3. Offer them all as a list

Write a JSON list of your models, each file (relative to the list) with the name to show, and put it beside them:

{"bracket.step": "Bracket", "case.stl": "Case"}

https://cad.place/?list=https://example.com/models/models.json opens the first; the others are in the model list in the toolbar (in the File menu, under Open…, on a phone). When the entries have pictures, File › Browse models… shows them as a grid. An entry can also carry a picture, a link to its product page, the source STEP file to download, its author and licence.

Before you publish, open the list check with your list's address: https://cad.place/check?list=https://example.com/models/models.json. It fetches every entry the way the viewer does and tells you what fails and why.

4. Embed the viewer in your page

<iframe src="https://cad.place/?embed=1&src=https://example.com/models/bracket.step" width="800" height="600" allowfullscreen></iframe>

The embedded view shows the model alone, with Fit, full screen (where the frame has allowfullscreen) and a link to open it in cad.place. Add &poster=<picture address> to show a picture first and load the model only when a visitor asks for it, and &theme=light for a white page (the default is dark).

The quickest way: open the model in cad.place, set the view, then File › Embed in a page… gives this code for that view, with the theme to choose and a Copy button.
